# github_user_activity

A CLI Github User Activity API App — built with pure Python.

---

## 📖 About

This is a program for an CLI based App to view user activity 

---

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or higher

- Username of whose actvity you want to see at https://github.com



### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/TheDevGod-Build/github_user_activity.git
   cd weather_api_app
   ```
2. **Run the program**
   ```bash
   python main.py
   ```

---
